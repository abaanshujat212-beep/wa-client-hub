Compliance Policy

WhatsApp / Meta

WA Client Hub is not affiliated with WhatsApp or Meta. Customers are responsible for complying with WhatsApp/Meta terms and all applicable laws.

Manual use only

The platform is designed for manual browser-based access. Do not use it for unauthorized automation, scraping, spam, or bulk messaging abuse.

Remote desktop security

Never expose raw RDP publicly. Use VPN, Cloudflare Access, Guacamole behind HTTPS, or another secured gateway.

Data security

Do not commit secrets, browser profiles, backups, or runtime data to Git. Browser profiles may contain active sessions and must be encrypted if backed up.

Customer onboarding

Customers should be informed that WhatsApp sessions run on assigned browser profiles and may require remote desktop access for calls.
