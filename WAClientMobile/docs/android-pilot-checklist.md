# Android pilot checklist

- Configure application ID, API base URL and release signing in secret storage.
- Install dependencies and verify a debug build on a physical Android device.
- Test login/session expiry, workspace authorization and logout cache cleanup.
- Test foreground/background notifications and incoming/outgoing call audio routes.
- Verify microphone permission denial, Bluetooth changes, network changes and call teardown.
- Build a signed internal APK/AAB, record version and rollback instructions, and obtain owner sign-off before pilot distribution.
