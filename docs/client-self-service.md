# Client self-service guide

Client dashboard supports the basic self-service flow:

1. Open **Workspaces**.
2. Create/select a workspace.
3. Add a WhatsApp number if the plan limit allows it.
4. Click **Link account** or **Open WhatsApp**.
5. Use **Open Remote Desktop** when configured.
6. Allow microphone/camera/notifications inside Chrome or Edge for `web.whatsapp.com`.

## Plan limits

The dashboard shows usage counters like:

- `Numbers: 1/3`
- `Users: 2/3`

If a limit is reached, the backend blocks the action.

## Support notes

If WhatsApp does not open:

- Confirm Windows host is online.
- Confirm Chrome/Edge is installed.
- Confirm remote desktop access works.
- Refresh dashboard and try again.
