# Customer setup guide

## 1. Login

1. Open the WA Client Hub URL.
2. Enter your email and password.
3. If you received an invite link, open it first and set your password.

## 2. Add WhatsApp number

1. Open **Workspaces**.
2. Select or create a workspace.
3. Click **Add number**.
4. Add label and phone number.
5. Click **Link account**.
6. Scan the WhatsApp Web QR code from the phone.

## 3. Open WhatsApp

- Click **Open WhatsApp** on the number card.
- WhatsApp opens on the assigned Windows desktop/browser profile.
- Each number has a separate Chrome/Edge profile.

## 4. Remote Desktop

If **Open Remote Desktop** is visible:

1. Click it.
2. Sign in to the secured remote desktop gateway.
3. Use the Windows desktop where WhatsApp Web is open.

Do not expose raw RDP publicly.

## 5. Microphone/camera

For calls:

1. Enable remote audio playback.
2. Enable microphone recording/redirection.
3. In Chrome/Edge, allow microphone and camera for `web.whatsapp.com`.
4. Place a test call.
